# Security Policy

## Scope

Rank the ABCs is a small Next.js site with one job: collect pairwise votes about
letters and fit them into an ordering. There are no accounts, no payments, and
nothing worth stealing in the database — a vote is a random session id and two
letters.

The parts that do carry risk:

- **The vote Server Action** — the only write path. It accepts a signed
  question token and an answer. The realistic threats are forging a token so
  you can vote on a question the server never asked, and stuffing the ballot at
  a rate the rate limiter does not catch. Both would corrupt the result, which
  is the entire product.
- **The question token** — an HMAC over the pair, the phrasing, the
  presentation order and the session. Anything that lets a client mint or
  tamper with one is a real finding.
- **Session handling** — the cookie is an opaque random id and nothing else. A
  way to read another visitor's session, or to make the "forget me" control
  fail to sever the link between a session and its votes, is a real finding.
- **Rendered content** — no visitor-supplied text is ever displayed, so there
  should be no injection surface at all. If you find one, that is worth
  reporting precisely because it should not exist.

## Out of scope

- Voting a lot, by hand, from one browser. That is called using the site.
- Automating votes at a human-ish pace. This is acknowledged in the design and
  cannot be prevented without a CAPTCHA, which is not worth it here.
- Reports generated by a scanner with no working proof of impact.

## Supported versions

Whatever is currently deployed at https://abc.findquinn.com. This is a side
project; fixes go forward, not into old tags.

## Reporting a vulnerability

Please report privately through
[GitHub Security Advisories](https://github.com/nooikko/rank-the-abcs/security/advisories/new)
rather than opening a public issue.

Include what you did, what happened, and the affected URL. A minimal
reproduction is the most useful thing you can attach. You will get a reply,
though it is a side project, so not necessarily a fast one.
